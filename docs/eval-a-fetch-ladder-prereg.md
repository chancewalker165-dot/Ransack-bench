# EVAL A pre-registration: fetch-ladder, difficulty-stratified (v1)

Status: PRE-RUN. Committed before any fetch call against ransack. The sample
manifest this document describes is generated by `scripts/build_fetch_sample.py`
and committed in the same push. If the manifest changes after fetches begin,
that is a BENCH_CHANGES.md event.

## Claim under test

"Ransack's fetch ladder retrieves the real content of hard pages at a measured
rate, and honestly labels the ones it cannot get, instead of returning soft-404
shells." This is the product's most differentiated claim and previously had no
number attached.

## Sample: 60 URLs, 7 strata, 10 each

Selection was designed to be independent of any prior ransack run knowledge:

1. **Candidate pools come from neutral public sources**, cited per stratum
   below, assembled before this document was committed.
2. **The draw is mechanical**: seeded RNG (seed 20260920) over the pool, no
   manual substitution. The seed and pool are in the committed manifest.
3. **Where a stratum's definition uses public knowledge** (e.g. which sites are
   SPA-rendered), the knowledge source is named and is restricted to publicly
   documented characteristics or ransack's own PUBLISHED docs claims (TikTok
   extraction fails; Amazon rejects plain fetch). Using the vendor's published
   admissions as test targets is adversarial but fair; using private run
   knowledge would not be, and is not done.
4. **No URL in the sample has appeared in any prior bench run.**

| Stratum | n | Pool source | Expected outcome |
|---|---|---|---|
| S1 plain-static | 10 | major documentation/static pages (MDN, RFC editor, project docs) | fact found |
| S2 tls-gated | 10 | sites documented in public engineering writeups as TLS-fingerprint gated | fact found or honest label |
| S3 js-rendered | 10 | publicly known SPA product/doc surfaces | fact found or honest label |
| S4 bot-walled retailer | 10 | product URLs of retailers from Wikipedia's largest-online-retailers list; product paths from the retailer's own public sitemap | honest wall label or fact found |
| S5 dead-or-404 | 10 | valid domains + non-existent paths (mechanical) | explicit failure with correct HTTP status |
| S6 paywalled | 10 | major paywalled publishers (WSJ, FT, NYT, Economist, Bloomberg, ...) | honest paywall label or explicit failure; success NOT expected |
| S7 archive-only | 10 | Wayback CDX draw of URLs with no live 200 at sample time | fact found from archive path or honest label |

## Ground truth protocol

- `fact_anchor`: a specific string that appears on the true content of the
  page. Captured at sample time by (a) plain urllib fetch (independent of
  ransack, and doubles as the no-ladder baseline), (b) a Wayback snapshot for
  S7, or (c) flagged `needs_owner_verification` for pages where neither works:
  those are verified by the owner in a normal browser BEFORE the eval runs.
  The owner pass is part of option 4 (sample review), not optional.
- `expected_outcome`: one of `fact_found`, `explicit_failure_with_status`,
  `honest_label_or_fact`.
- Scoring per call:
  - success: `fact_anchor` present in returned content
  - honest-failure: no content + truthful label (status or wall label)
  - **dishonest: content returned, fact absent, no label** (the soft-shell
    failure mode; this is the number that must be small)
- Headline metrics: success rate per stratum; wall/failure-label precision and
  recall against expected outcomes; dishonest-shell rate (target: ~0).

## Baselines

- Plain urllib fetch (no ladder): run on every URL, same scoring. The delta
  between plain fetch and ransack IS the ladder's measured value.
- Firecrawl column optional (needs a key; owner decision, not blocking).

## Procedure after sign-off

1. Owner reviews sample (this is the option-4 gate): spot-check 5-10 URLs in a
   browser, confirm strata labels and fact anchors, edit manifest flags only.
2. Run: ransack fetch + plain urllib baseline over all 60.
3. Report: per-stratum table, label precision/recall, dishonest-shell count,
   raw transcripts. Losses published as-is.

## Bias disclosure

- The author of this eval is also the operator of the product being measured.
  The mitigations are: mechanical seeded draw, pre-registration of this file
  before any call, neutral pool sources, fact anchors captured independently of
  ransack, owner browser-verification of flagged entries, and everything
  (sample, transcripts, misses) committed. A fully independent third-party run
  remains the strongest verification and is still the open ask.
