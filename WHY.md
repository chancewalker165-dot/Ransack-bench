# Why I built this

Everyone's search tools filled one piece of the puzzle. I pulled the pieces together into one thing my agents can actually use: the latest information, gathered to open-research standards, wrapped in a single MCP instead of five. One tool, Ransack.

I hold Ransack to the same standard I want from it: there's a public benchmark in this repo that grades it against competitors, and it shows rows where we lose. Read it before you trust anything on this page.
